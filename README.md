# Решение задачи машинного обучения

В рамках этого домашнего задания были решены три типовые задачи анализа данных с использованием Python и библиотек Scikit-learn, Statsmodels и Matplotlib.

## Часть 1. Классификация (Synthetic Classification)

Целью было сравнить качество различных алгоритмов классификации на синтетических данных.

**Что сделано:** Сгенерирован датасет из двух классов с помощью функции `make_blobs`. Проведен поиск оптимальных гиперпараметров для четырёх моделей: логистическая регрессия, SVM, дерево решений и случайный лес. Качество оценено через коэффициент Джини.

**Результаты:** Лучшую точность показала модель *Логистическая регрессия* с параметром регуляризации $C=0.1$ ($Gini = 0.785$). Модель Random Forest также показала хорошие результаты при ограничении глубины деревьев до 5 уровней.

**Выводы:** Для простых линейно разделимых данных логистическая регрессия оказалась наиболее эффективной. Деревья решений склонны к переобучению без ограничения глубины.

## Часть 2. Регрессия (Synthetic Regression)

Задача заключалась в анализе мультиколлинеарности признаков и построении модели бэггинга.

**Что сделано:** Создан синтетический набор данных со специально введённой высокой корреляцией между признаками. Построена модель линейной регрессии с ансамблевым методом BaggingRegressor. Оценка качества проведена по метрикам MSE и R².

**Результаты:** Модель показала высокий коэффициент детерминации $R^2 \approx 0.96$, однако анализ VIF выявил сильную мультиколлинеарность (VIF > 10 у большинства признаков).

**Выводы:** Бэггинг эффективно снизил дисперсию предсказаний, но высокая корреляция между признаками затрудняет интерпретацию важности отдельных факторов. Для реальных данных рекомендуется использовать методы отбора признаков или Lasso-регрессию.

## Часть 3. Временные ряды (Time Series Forecasting)

Требовалось спрогнозировать искусственно созданный временной ряд с трендом и сезонностью.

**Что сделано:** Ряд был представлен как сумма синусоиды, линейного тренда и шума. Применены две классические модели: авторегрессионная AR и экспоненциальное сглаживание ETS/Holt-Winters. Прогнозы визуализированы и оценены по MAE и RMSE.

**Результаты:** Модель Holt-Winters (ETS) показала меньшие ошибки прогноза на тестовом участке ($MAE_{ETS} < MAE_{AR}$), особенно хорошо справившись с воспроизведением сезонных колебаний.

**Выводы:** При наличии явной сезонности и тренда модель ETS является предпочтительной. Метод AR требует стационарности ряда после взятия разностей, что усложняет настройку параметров.
